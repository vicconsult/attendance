OFFICE ATTENDANCE TRACKER

Privacy

PRIVACY

Private attendance without continuous location tracking

Office Attendance Tracker uses a reserved username and a private random token. Attendance records are stored in the application MySQL database so an iPhone Shortcut can record a visit without opening the web app.

What is stored

The server stores your username, a one-way hash of your private token, and attendance records such as date, office label, check-in time, source and office time zone. Your raw private token is not stored in MySQL; only its SHA-256 hash is stored.

Location

The web app does not receive continuous GPS coordinates. Your iPhone Shortcuts Arrive automation handles the location geofence. The server receives an office label when that automation calls the private check-in URL.

Your private token

The private token is the credential to your attendance account. Keep it and generated Shortcut URLs private. The browser stores the token locally on devices you connect.

Server logs

A Shortcut URL contains the private token. Configure the web server or reverse proxy not to log query strings for the /checkin endpoint. Infrastructure outside this application may otherwise record requested URLs.

Backups

You can export attendance history as a JSON file and import it later. The exported backup does not need to include your private token.
