FAQOffice attendance tracker questions ⌄
Can the iPhone check in while the phone is locked?

The automation uses Get Contents of URL, which sends a web request instead of launching Safari. The server records the attendance and the dashboard can be reviewed later.

Can I track attendance across multiple offices?

Yes. Create one Arrive automation per office and give each check-in URL a different office name and time zone.

Does it prevent duplicate attendance?

Yes. The server stores a maximum of one attendance record per calendar day for each username, even if you leave and return to an office.

Does the app continuously track my location?

No. The iPhone's Arrive automation handles the geofence. The server receives an office check-in request, not continuous GPS coordinates.

Is the office attendance tracker free?

Yes. It does not require a paid mapping service.
