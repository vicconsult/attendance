Record office attendance without opening Safari

Use an iPhone Shortcuts Arrive automation together with Get Contents of URL. The iPhone decides when you enter the office geofence, then sends a private check-in request to the server.

Set up an office automation

  1. Open the tracker and reserve a username. Save the private token shown after registration.
  2. In the tracker, enter the office name and office time zone, then tap Copy URL.
  3. Open Shortcuts → Automation on the iPhone and create an Arrive automation.
  4. Select the company office location and geofence radius.
  5. Choose Run Immediately.
  6. Choose New Blank Automation, then add Get Contents of URL.
  7. Paste the private check-in URL generated by the tracker.
  8. Save the automation. The action sends a web request instead of opening Safari.

Multiple offices

Create one Arrive automation for each office. Generate a separate URL with that office's name and time zone. All automations use the same username/private token and still count a maximum of one attendance day per date.

Attendance rules

The server counts Monday through Friday only, from 5:00 AM through 3:00 PM in the time zone included in that office's check-in URL.

Keep the URL private

The generated URL contains your private token. Anyone with that full URL could submit a check-in to your account. Do not share it, and configure server access logging so the /checkin query string is not retained.

Review your RTO progress

The dashboard shows office days by week, a rolling 12-week average, visits needed to reach the target, attendance history and statistics for each office.
